---
name: Plan progress tracking
description: Project rule for maintaining the implementation status in Plan.MD.
---

For this project, update `Plan.MD` whenever a planned item starts or is completed. Mark an item complete only after its result has been checked, and keep the status summary and blockers current.

**Why:** the user asked to use `Plan.MD` to see how far project work has progressed.

**How to apply:** before and after implementing a planned item, update its checklist state and the overall project status in `Plan.MD`.
